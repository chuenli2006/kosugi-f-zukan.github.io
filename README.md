# 🌸 風俗履歴図鑑 (Fuzoku History Zukan)

「風俗履歴図鑑」は、お気に入りのキャスト情報やこれまでの利用記録、手紙・メッセージカード、プレイの思い出をスマートかつスタイリッシュに管理できる個人用Webアプリケーションです。

アプリの動作リンクはこちら：
- **通常版 (Stable):** [https://chuenli2006.github.io/kosugi-f-zukan.github.io](https://chuenli2006.github.io/kosugi-f-zukan.github.io)
- **開発中バージョン (Dev):** [https://chuenli2006.github.io/kosugi-f-zukan.github.io/dev.html](https://chuenli2006.github.io/kosugi-f-zukan.github.io/dev.html)
- **簡易バージョン (light):** [https://chuenli2006.github.io/kosugi-f-zukan.github.io/stable.html](https://chuenli2006.github.io/kosugi-f-zukan.github.io/stable.html)

---

## 🌟 主な機能紹介

### 1. キャスト別図鑑 ＆ 月別時系列ビュー
- **キャスト別管理:** 利用回数やオキニ度（⭐️・🆂・⚔などのマーク）に応じてカードが美しく色分けされます。在籍状況や旧源氏名、スリーサイズ（体型に応じた自動カラーリング機能付き）もひと目でわかります。
- **月別時系列ビュー:** 過去の利用履歴を月ごとにタイムライン形式で振り返ることができます。

### 2. 📊 利用統計ダッシュボード
- 総利用回数、経験人数、現在在籍しているキャスト数、オキニ率などのスタッツを自動集計・リアルタイム表示します。

### 3. 📤 友だちへの共有機能 ＆ ガイド
- **個別選択シェア:** キャストごとの基本情報、利用履歴を `.json` ファイルとして書き出し可能です。
- **STEPガイド:** 共有モーダル内に「STEP 1〜3」の分かりやすい共有ガイドカードを搭載し、ファイル作成からLINEやDiscordでの送信、受け取りまで迷わず行えます。

### 4. 💌 メッセージカード（手紙）コレクション
- キャストから貰った手紙やメッセージカードの写真・テキストを日付順に美しくファイリング。いつでも思い出を振り返ることができます。

### 5. 🎨 10種類のカラーテーマ着せ替え
- ぴんく、ミッドナイト・ローズ、ベルベット・ブラック、スモーキー・ベリー、サイバー・ネオン、ダーク・モカ、エメラルド、シャンパン・ゴールド、ヴァイオレット、ピーチなど、気分に合わせてUIカラーを自由自在に変更可能です。

### 6. 🎰 運命の指名ガチャ機能
- 在籍中のキャストからランダムで次の指名先を楽しく選出してくれるガチャ演出を搭載しています。

### 7. 📂 バックアップ & データ管理
- すべてのデータをJSONファイルとして一括ダウンロード保存したり、ファイルを選択して簡単に復元・移行することができます、機種変するときに便利です。
